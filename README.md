# Oncology Research Intelligence Agent (ORIA)

**Vision**  
ORIA is an AI-powered research copilot that helps researchers, analysts, and operational teams instantly find, summarize, and analyze information across cancer research documents and trial data.  

**Key Features**  
- Document ingestion (PDFs, DOCX, etc.)
- Metadata extraction (e.g., Cancer type, Drug names, etc.)
- Semantic search for oncology studies
- Research Chat Agent for summaries and insights
- Trial analytics and reporting

**Roadmap**  
- Phase 0: Lab Replication
- Phase 1: Research Repository MVP  
- Phase 2: Metadata Extraction  
- Phase 3: Research Chat Agent  
- Phase 4: Analytics Layer
- Phase 5: Streamlit Frontend  
- Phase 6: Executive Demo
